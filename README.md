# Galleon Voyage v5 — 3D 远洋古帆船与沉浸伴航白噪音模拟

零外部美术与音频资产、纯 Three.js (r170) + Web Audio API 程序化构建的 3D 航海与解压伴航模拟。

## v5 新增核心特性
- **一键「沉浸伴航 / 风暴炉火解压模式」（快捷键 `Z`）**：隐藏全部常规战斗与罗盘界面，仅保留极简悬浮条（静置自动淡隐），可一键切换「极地暴雪」「雷暴夜航」「星夜暖灯」三大解压主题，支持电影慢镜自动巡航与船长室舷窗观景。
- **船长室复古木框舷窗视角（`V` 切换或伴航模式一键进入）**：隔着挂满动态折射雨滴或冰霜结晶的橡木窗棂观赏风暴；室外风雪雷雨经舱内隔音低通滤波自然闷响，屋内炉火噼啪与船壳吱呀保持通透温暖。
- **船尾防风炭火盆**：三脚锻铁架、炭火床、双层摇曳火焰、上升余烬火星与暖橙摇曳点光源，与窗外冷冽风雪/暴雨形成强烈庇护感反差。
- **极地暴雪天气（快捷键 `5`）与可碰撞浮冰物理**：1,800 粒子 GPU 旋涡暴雪、极光微光夜空与 18 块带真实浮力与船体碰撞物理的多边形浮冰（撞击时按冲量弹开、翻滚、溅起碎冰并同步触发冰裂音效与微震动）。
- **5 轨独立程序化白噪音混音台与助眠定时**：独立调节「雨雪声 / 狂风索具 / 深海涌浪 / 船体碰撞 / 炉火噼啪」，内置 `15 / 30 / 60 分钟` 定时助眠并在最后 60 秒自动平滑淡出静音。
- **物理声画联动升级**：大浪狠砸船首（Bow Slam）同步触发浪花爆发、镜头微震与低频闷响泼水声；闪电按模拟距离（150–360m）产生 `0.32–2.35s` 光声延迟，近雷清脆、远雷沉闷。

## 快捷键一览
- `Z`：开启 / 退出沉浸伴航解压模式（`Esc` 退出）
- `1–6`：正午晴空 / 日落余晖 / 星夜极光 / 雷暴骤雨 / 极地暴雪 / 滔天海啸
- `A / D` 或 `← / →`：360° 持续左舵 / 右舵转向（波浪迎向同步旋转）
- `W / S`：帆力推进加减速
- `V`：切换 6 大机位（自由环绕 / 舵轮船长 / 船首破浪 / 桅顶瞭望 / 电影巡航 / 船长室舷窗）
- `Q / E / Space`：左舷 / 右舷 / 双舷 16 门火炮齐射
- `M`：音效开关 · `B`：船首铜钟 · `G`：画质档位（高/中/低） · `H`：纯净隐藏界面 · `P`：高清截图
